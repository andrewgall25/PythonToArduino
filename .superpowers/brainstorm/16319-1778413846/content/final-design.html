Design Summary

  • Palette: GitHub Dark Glow — #0d1117 bg, #161b22 input, #30363d borders
  • Font: JetBrainsMono (moved from assets to res/font for Compose)
  • Timestamps: HH:mm labels between message batches, #484f58 subtle color
  • Header: Green dot + title + icon toolbar (copy & clear/trash)
  • Input: Pill-shaped, green glow on hover, green send button
  • Message colors: Color-coded by type — commands, arduino, errors
